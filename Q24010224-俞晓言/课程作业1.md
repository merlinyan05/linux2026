## SSH 服务验证

在 Ubuntu 中检查 SSH 服务：

```bash
systemctl is-active ssh
```

输出结果：

```text
active
```

查看 Ubuntu 虚拟机的 IPv4 地址：

```bash
ip -4 -br addr
```

输出结果：

```text
lo      UNKNOWN  127.0.0.1/8
enp0s1  UP       192.168.64.3/24
```

在 macOS 终端中连接 Ubuntu：

```bash
ssh merlin@192.168.64.3
```

验证结果：成功登录，远程终端提示符为：

```text
merlin@merlin-ubuntu:~$
```
